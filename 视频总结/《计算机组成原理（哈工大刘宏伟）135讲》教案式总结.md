## 一、全局知识地图

计算机组成原理回答的不是“程序写了什么”，而是程序如何被表示、保存、取出、运算、控制并与外部世界交换信息。整套课程可以沿着下面的闭环学习：

```text
信息表示 → 存储与寻址 → 运算器处理 → 指令描述任务
    ↑                                      ↓
外设与总线 ← CPU执行与控制 ← 控制器产生时序和控制信号
```

理解任何一个部件，都可以连续追问四件事：数据是什么编码？现在位于哪里？下一步由谁搬运？控制信号和时序如何保证动作正确？

## 二、十章系统讲解

### 第 1 章：计算机系统概论

计算机系统由硬件和软件共同构成。硬件提供运算器、控制器、存储器以及输入输出设备；软件把用户任务组织成指令和数据。组成原理关心的是二者的接口：程序中的操作如何变成机器指令，机器指令如何驱动数据通路完成动作。

最基本的五大功能部件是运算器、控制器、存储器、输入设备和输出设备。运算器处理数据，控制器解释指令并产生控制信号，存储器保存指令和数据，I/O 设备承担计算机与外部环境之间的信息交换。冯·诺依曼结构的关键是“存储程序”：指令和数据以二进制形式存储在存储器中，CPU 按地址取指并执行。

性能不能只看主频。程序执行时间由指令条数、每条指令所需的平均周期数 CPI 和时钟周期共同决定：`CPU 时间 = 指令条数 × CPI × 时钟周期`。因此编译器减少指令条数、体系结构降低 CPI、工艺提高主频，都是可能的优化方向，但它们的代价和适用范围不同。

### 第 2 章：计算机的发展、应用与展望

计算机的发展经历电子管、晶体管、集成电路、大规模集成电路等阶段。器件尺寸下降和集成度提高，使速度、容量、可靠性和能效不断改善；体系结构又通过并行处理、流水线、层次化存储和专用加速器继续扩大性能边界。

计算机应用从科学计算扩展到事务处理、嵌入式控制、个人计算、移动终端、云计算和人工智能。应用变化会反过来影响机器设计：实时控制看重确定性和响应时间，服务器看重吞吐率和可靠性，移动设备看重能耗和集成度。理解计算机发展时，要同时看器件、体系结构、软件生态和应用需求。

### 第 3 章：系统总线

总线是多个部件共享的传输通道，通常由地址线、数据线和控制线组成。地址线说明访问对象，数据线承载指令或数据，控制线说明读写方向、时序和请求/应答关系。按传输对象可分为片内总线、系统总线、I/O 总线；按数据传送方式可区分并行和串行，按时序可区分同步和异步。

一次总线事务可以抽象为：主设备提出请求并给出地址，仲裁逻辑决定谁获得总线，主设备发出控制信号，从设备响应并完成数据传输，最后释放总线。总线带宽受到数据宽度、工作频率、传输效率和等待周期影响；总线越共享，越需要仲裁和时序控制来避免冲突。

常见总线结构有单总线、双总线和多总线。单总线连接简单但竞争严重；多总线可以把 CPU、主存和 I/O 的传输分开，提高并行性但增加硬件复杂度。学习总线题时，要明确主从关系、地址/数据/控制的先后顺序，以及同步或异步方式下的握手信号。

### 第 4 章：存储器系统

存储器的核心任务是保存比特，并能依据地址读出或写入数据。存储系统存在速度、容量和成本之间的矛盾，因此形成寄存器、Cache、主存和辅助存储器的层次结构：越靠近 CPU，速度越快、容量越小、单位成本越高。层次结构能够有效工作的根本是时间局部性和空间局部性。

主存由存储单元、地址译码器、读写控制电路和数据缓冲结构组成。芯片容量计算要区分“字数”和“每字位数”：地址线数决定可选单元数，数据线数决定并行数据宽度。多片芯片可通过位扩展增加字长，通过字扩展增加字数；片选信号负责把地址空间分配给不同芯片。

SRAM 以触发器保存信息，速度快、集成度较低，常用于 Cache；DRAM 以电容电荷保存信息，容量大但需要刷新，常用于主存。ROM 及其可改写类型适合保存非易失信息。辅助存储器容量大、断电保留数据，但访问延迟远高于主存。

Cache 通过把最近使用或相邻的数据复制到高速存储器中减少平均访存时间。直接映射、全相联和组相联的区别，本质是主存块可以放入 Cache 的位置数不同。地址通常拆成标记、组号和块内地址：先用组号定位，再比较标记，命中则按块内地址取数，缺失则从下一层调入。写直达、写回、写分配等策略是在一致性、带宽和复杂度之间取舍。

### 第 5 章：输入输出系统

外设在速度、数据格式、控制方式和电气接口上与 CPU/主存不同，因此需要 I/O 接口完成缓冲、状态记录、控制命令和数据格式转换。典型接口至少包含数据寄存器、状态寄存器和控制寄存器，CPU 通过端口或存储器映射方式访问它们。

程序查询方式由 CPU 主动反复检查设备状态，硬件简单但会产生忙等待。中断方式让设备在准备好或发生事件时提出请求，CPU 完成当前可中断指令后保存现场、转入中断服务程序，处理完再恢复原程序，因而提高了 CPU 利用率。DMA 方式把成块数据传送交给 DMA 控制器，设备和主存直接交换数据，CPU 只需初始化和收尾，适合高速、大批量传输。

比较 I/O 方式时，应同时看 CPU 介入频率、传送粒度、硬件复杂度、响应及时性和总线占用。中断减少等待但仍有每次服务开销，DMA 减少 CPU 介入但需要 DMA 控制器并竞争总线。

### 第 6 章：计算机中数的表示与运算

计算机只能处理位模式，位模式的意义由编码规则决定。无符号数使用各位的二进制权值；有符号数需要规定符号和负数编码。原码直观但存在两个零，反码也存在两个零，补码只有一个零且能用同一套加法器完成加减，因此现代整数运算普遍采用补码。移码通过改变偏置，便于比较阶码大小。

定点数把小数点位置固定，运算简单但表示范围有限；浮点数用符号、阶码和尾数分别表达正负、数量级和精度，能覆盖更大范围。浮点加减要依次完成对阶、尾数加减、规格化和舍入；浮点乘除要分别处理阶码和尾数，并检查溢出、下溢与精度损失。

定点乘除可以由加法器、移位寄存器、部分积/余数寄存器和控制逻辑迭代完成。ALU 是运算器的核心，它根据操作选择信号完成算术、逻辑、移位和比较，并产生进位、零、符号、溢出等状态标志。理解算法时，应把每一步数学操作对应到寄存器内容、移位方向和控制信号。

### 第 7 章：指令系统

机器指令是软件向硬件发出的精确命令，通常包含操作码和操作数字段。操作码说明做什么，地址或寄存器字段说明对谁做。操作数可以来自寄存器、主存或指令中的立即数；寻址方式规定如何由形式地址形成有效地址，例如直接、间接、寄存器、寄存器间接、相对和变址寻址。

指令格式设计要在操作码数量、地址字段数量、指令长度、译码难度和程序代码密度之间权衡。零地址、单地址、二地址和三地址指令对应不同的操作数组织方式。RISC 强调规整定长指令、少量简单寻址方式和大量寄存器，便于流水线和快速译码；CISC 则保留更丰富的指令和寻址形式，以提高单条指令表达能力。

### 第 8 章：中央处理器

CPU 的数据通路由 PC、IR、通用寄存器、MAR、MDR、ALU、移位器和内部总线等组成，控制器决定何时选择哪条通路、何时读写哪个寄存器。取指阶段通常是：PC 送地址寄存器，主存读出的指令进入 MDR，再装入 IR，同时 PC 更新到下一条指令。译码后，CPU 根据指令类型形成有效地址并执行操作。

指令周期可分为取指、间址、执行和中断等阶段，具体机器可以合并或细分。每个阶段又由若干微操作构成，时钟保证这些微操作按顺序完成。流水线把取指、译码、执行、访存和写回重叠，使多条指令同时处于不同阶段；结构冲突、数据冲突和控制冲突会引入停顿、旁路、气泡或分支处理代价。

中断系统把外部事件纳入 CPU 控制流。CPU 需要完成请求检测、优先级判定、响应、保存断点和现场、转入服务程序、恢复现场和中断返回。中断的关键不是“马上停止”，而是在满足屏蔽、优先级和指令边界条件后进行可控的控制转移。

### 第 9 章：控制单元的功能

控制单元把机器指令的语义转换为控制信号序列。设计时先分析指令在数据通路上需要完成哪些微操作，再按时序把微操作分组，最后确定每个状态下的寄存器选择、ALU 操作、存储器读写和 PC 更新信号。操作码、时序状态和条件标志共同决定下一步动作。

以取指为例，控制器要依次安排 PC 输出到地址寄存器、发出存储器读命令、把数据送入指令寄存器、修改 PC 等动作。执行不同指令时，控制器根据操作码选择不同的微操作路径；遇到间接寻址、中断或分支，还要根据条件结果改变后续状态。

### 第 10 章：控制器的设计

硬布线控制器把操作码译码、时序状态和条件标志送入组合逻辑，直接生成控制信号，速度快但修改指令系统或增加复杂控制逻辑较困难。设计过程通常包括建立微操作流程、列出控制信号条件、形成逻辑表达式并实现时序电路。

微程序控制器把控制信号编码为微指令，微指令存放在控制存储器中，微地址形成部件负责顺序执行、按操作码转入口以及按条件分支。它把复杂控制逻辑变成可修改的微程序，设计和扩展更灵活，但多了一层微指令读取开销。两者共同说明：一条机器指令最终都要落实为按时钟推进的一串微操作。

## 三、贯穿全课的公式与判断框架

- **CPU 执行时间**：`CPU 时间 = 指令条数 × CPI × 时钟周期`。主频只决定时钟周期，不能单独代表程序性能。
- **存储容量**：`容量 = 存储单元数 × 每单元位数`；地址线数决定可寻址单元数量，数据线数决定一次并行传输宽度。
- **Cache 平均访问时间**：`平均时间 ≈ 命中时间 + 缺失率 × 缺失代价`。局部性越好，层次化存储越能接近高速存储器的体验。
- **补码**：正数按原码表示，负数按模减去绝对值或按“按位取反加一”得到；加法器可以统一完成加减，但必须判断溢出。
- **浮点数**：通常写成 `(-1)^S × 1.M × 2^E`，其中符号、阶码和尾数分别承担正负、数量级和有效精度。
- **流水线吞吐率**：理想情况下，阶段数增加主要改善单位时间完成的指令数；单条指令延迟、冲突和填充排空开销仍需单独分析。
- **有效地址**：不同寻址方式只是“指令中的地址字段如何形成真正操作数地址”的不同规则，解题时要逐步写出中间地址。

遇到计算题时，统一采用“读条件 → 确定编码/字段 → 按时序执行 → 检查范围与边界 → 用另一种方式验算”的顺序。

## 四、跨章节主线：一条指令怎样跑起来

1. 程序和数据先以二进制编码存放在存储系统中，PC 保存下一条指令地址。
2. CPU 通过总线或内部数据通路把指令取入 IR，控制器根据操作码识别指令类型和寻址方式。
3. 若需要访存，地址形成部件计算有效地址，Cache/主存层次负责把操作数送到 CPU。
4. ALU 或移位部件完成运算，标志寄存器记录进位、零、负和溢出等状态。
5. 结果写回寄存器或存储器；若流水线中还有后续指令，则通过阶段重叠提高吞吐率。
6. 外设请求到来时，CPU 可以查询状态、响应中断，或让 DMA 控制器直接完成成块传送。

## 五、常见题型与易混概念

| 题型 | 解题抓手 | 常见错误 |
|---|---|---|
| 编码与进制 | 先确定位权、位宽和符号解释 | 把位模式和值混为一谈 |
| 补码运算 | 统一位宽，逐位相加，最后判断溢出 | 把进位丢弃误认为没有溢出 |
| 存储器容量 | 分清地址线、数据线、片选和字扩展/位扩展 | 地址空间与芯片容量混淆 |
| Cache 映射 | 拆分块内地址、组号、标记 | 忽略块大小或把字节地址当块号 |
| 指令寻址 | 写出有效地址形成过程 | 直接把形式地址当有效地址 |
| 指令周期 | 按 PC、IR、MAR、MDR 和寄存器变化列微操作 | 跳过取指、间址或写回 |
| 流水线 | 画时间-空间图，逐项检查冲突 | 只套理想公式，不处理停顿 |
| I/O 方式 | 比较 CPU 介入频率、传送粒度和硬件代价 | 认为 DMA 完全不占用总线 |

**不要混淆：** 主存与 Cache 是存储层次的不同层；中断是控制转移机制，DMA 是数据传送机制；硬布线控制依靠逻辑电路，微程序控制依靠控制存储器中的微指令；主频、CPI 和指令条数共同决定 CPU 时间。

## 六、给初学者的学习路线

第一轮先按“系统组成 → 总线/存储 → 数的表示与运算 → 指令 → CPU/控制器”建立结构，不急着背公式。第二轮集中练习编码、容量、Cache、补码、寻址、指令周期和流水线。第三轮用完整数据流复盘“取指—译码—执行—访存—写回”，并比较查询、中断和 DMA 的适用场景。

每学完一集，至少能回答：本节解决什么问题？输入和输出是什么？涉及哪些寄存器、线路或存储层次？它与前后哪一节相连？若是计算题，哪个条件最容易导致边界错误？

## 结语

计算机组成原理的核心不是孤立记忆部件名称，而是把编码、存储、运算、指令、控制、总线和 I/O 串成一条可追踪的数据流。真正掌握一节内容的标志，是能够从一个具体指令或一次数据传送出发，说清楚数据在哪里、如何表示、经过谁处理、由什么信号控制，以及速度提升付出了什么代价。

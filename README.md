# Zyl's Obsidian 知识库

这是一个以 Obsidian 为载体的个人学习与知识整理仓库，主要记录课程学习、视频总结、软件工程思考、英语学习方法和 AI 工具使用经验。

仓库的整理原则是：把零散的课程、视频和网页内容转化为可检索、可编辑、可复习的 Markdown 笔记，并通过 Git 保留持续更新的版本记录。

## 知识主线

当前学习内容可以归纳为三条相互关联的主线：

- **系统学**：理解事物的整体结构、组成部分、交互关系和运行规律。
- **管理学**：学习如何协调人、物、信息和资源，以实现明确目标。
- **工程学**：面向实际问题进行设计、实现、验证和改进，把知识转化为可用成果。

这三条主线贯穿于计算机组成原理、软件工程、Java Web、生命科学、水产相关课程以及 AI 辅助学习等内容。

## 内容概览

### 课程与视频总结

`视频总结/` 保存根据课程和公开视频整理的教案式 Markdown 笔记，目前包括：

- **计算机组成原理**：从课程介绍和基础概念入手，梳理计算机硬件系统的组成与运行。
- **软件工程**：整理软件工程的基本概念、开发过程、方法和过程模型。
- **生成式软件工程**：记录 AI、LLM、Agent 与软件工程的关系，重点讨论需求理解、规格设计、系统结构、验证和可维护性。
- **英语学习方法**：总结词表学习、主动提取、间隔复习和语境式学习等方法。

笔记的目标不是逐字保存视频，而是提炼概念、因果关系、案例和可复习的问题，方便后续检索与补充。

### 课程框架整理

根目录中的 `大三上课程关键词.md` 从“系统学、管理学、工程学”三个角度，整理计算机、软件工程、生命科学和水产相关课程之间的联系，用于建立整体课程认知。

### Codex 使用资料

`Codex 介绍.md` 介绍 OpenAI Codex 的基本能力、典型工作流程、适用场景和使用注意事项，重点强调先理解上下文、再实施修改，并通过验证完成交付。

### 网页剪藏与使用记录

`Clippings/` 用于保存从网页或其他来源剪藏的资料，例如 AI 工具使用记录、数据摘要和相关参考内容。

## 仓库结构

```text
.
├── 大三上课程关键词.md     # 课程体系与学习主线
├── Codex 介绍.md           # Codex 使用说明
├── 视频总结/                # 课程与公开视频学习笔记
├── Clippings/              # 网页剪藏和资料记录
├── .obsidian/               # Obsidian 配置与已启用插件配置
└── .gitignore               # 临时文件与本地会话排除规则
```

视频下载、转码、截图和转录过程中产生的文件位于本地的 `视频总结/_video_summary_tmp/` 目录，并由 `.gitignore` 排除，不作为仓库的长期内容。

## 使用方式

1. 使用 Obsidian 打开仓库根目录。
2. 通过文件列表、全局搜索、标签、反向链接和图谱浏览笔记。
3. 阅读视频总结时，优先关注每篇笔记的结论、案例、关键概念和复习问题。
4. 新增或修改笔记后，使用 Obsidian Git 或 Git 命令提交并推送更新。

## Git 同步

当前仓库使用 `main` 分支，并通过 `origin` 连接到 GitHub：

```text
https://github.com/ZHUO928/zyls-obsidian.git
```

仓库保留了部分 Obsidian 配置以及 `obsidian-git`、`realclaudian` 插件配置，便于恢复基本的笔记环境。Claudian 会话记录、视频处理临时文件和 Obsidian 回收站不会纳入版本控制。

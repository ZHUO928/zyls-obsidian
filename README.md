# Zyl's Obsidian 知识库

这是一个个人 Obsidian 知识库，用于整理课程学习、视频内容、软件工程思考、英语学习方法以及 AI 工具使用记录。

## 内容概览

### 视频总结

`视频总结/` 保存从课程和公开视频中整理出的 Markdown 笔记，当前包括：

- 《生成式软件工程》第一课：AI 时代的软件工程、Agent、人机协作、需求规格、验证和可维护性。
- 软件工程概述：软件工程基础概念、开发过程、方法和过程模型。
- 这学期课程关键词：从系统学、管理学和工程学三个角度梳理后续课程。
- 如何永远学会一个单词：词表学习、主动提取和语境式学习方法。

这些笔记强调把视频内容转化为可检索、可编辑和可持续更新的知识材料，而不是只保留视频本身。

### Codex 使用资料

根目录中的 `Codex 介绍.md` 介绍 OpenAI Codex 的基本能力、典型工作流程、适用场景以及使用时的注意事项。

### Clippings

`Clippings/` 用于保存从网页或其他来源剪藏的资料，例如 AI 工具使用记录和相关数据摘要。

## 仓库结构

```text
.
├── Codex 介绍.md          # Codex 使用说明
├── 视频总结/               # 课程与视频学习笔记
├── Clippings/              # 网页剪藏和资料记录
├── .obsidian/              # Obsidian 配置与已启用插件配置
└── .gitignore              # 本地临时文件排除规则
```

## 使用方式

1. 使用 Obsidian 打开仓库根目录。
2. 在文件列表中浏览或搜索 Markdown 笔记。
3. 使用双向链接、标签、反向链接和图谱继续组织知识。
4. 修改内容后，通过 Obsidian Git 或 Git 命令提交并推送更新。

## 同步说明

仓库通过 Git 管理版本，并保留了部分 Obsidian 配置，便于在其他设备上恢复基本的笔记环境。视频处理过程中产生的音频、视频、截图和临时转录文件不会纳入 Git，由 `.gitignore` 排除。
